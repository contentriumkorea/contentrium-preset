# Contentrium Preset 검증과 지원 범위

검증 환경: Windows 11, After Effects 2026(26.5), 2026-10-15~16.

## 1.1.1 미리보기 검증

개체 50개 변형은 투명 로고 PNG, 텍스트 25개와 타이틀 6개는 배경 이미지 없는 글자, 장면 전환 26개는 서로 다른 새 A/B 이미지, 도형 3개는 자체 도형을 사용하도록 미리보기 구성을 변경했습니다. 새 자산은 로고 1254×1254 RGBA PNG와 두 장면 1672×941 PNG입니다. 생성 방식과 프롬프트는 [미리보기 자산 기록](preview-assets.md)에 있습니다.

새 피사체로 AE 컴포지션 110개를 구성하고, 종류별 레이어·이미지 경로·크기·위치·전환 구간 검사 110개를 통과했습니다. 110개 모두 AE에서 다시 렌더했습니다. 배포 영상은 320×180, 30fps, 1.466~5.533초의 WebM이며 합계 5,624,084바이트입니다. 대표 8종의 40개 프레임을 직접 확인했습니다. 이 표본 검사는 전체 110개 동작 구간의 시각 검사를 뜻하지 않습니다.

브라우저에서 새 영상 110개의 디코딩·프레임 읽기·변형 선택·하단 이름/방향 표시와 파일 해시를 확인했습니다. From End/From Start, View all at once와 Back의 선택 유지, 43개 카드 중 화면 밖 27개의 정지·시간 유지와 스크롤 후 재생 재개도 통과했습니다. 미디어·HTTP·콘솔 오류는 0개였습니다. 카드 교체에 따른 정상 요청 취소는 오류와 구분했습니다.

Node 검사 74개와 패키지 검증을 통과했습니다. 영상 대신 표시하는 대체 미리보기 대표 7종과 A/B 이미지 로딩도 확인했습니다. 로고 크기와 긴 그림자 길이는 AE 기준 화면 비율에 맞췄습니다. 브라우저 검사는 AE 호스트 응답을 대체하거나 가짜로 생성하지 않았습니다.

### 1.1.1 설치와 설치된 엔진

2026-10-16에 최종 `Setup.exe`의 격리 설치 검사 16개, 무인 설치 검사 7개, 패키지 메타데이터 검사 4개를 통과했습니다. 공개 배포에서 세 파일을 다시 내려받아 원본 빌드와 크기·SHA-256이 모두 일치함을 확인했습니다.

| 파일 | 크기 | SHA-256 |
| --- | --- | --- |
| Setup.exe | 45,568바이트 | `d5fa067c4a796f290b0d8e2a70b79d12576f4ac9a64da39319762b3902f8a236` |
| Portable.zip | 13,570,161바이트 | `aacdec66e151205fc981fe6e598e5f96a785e0b31057d609aa0984ed8dcec113` |
| release-manifest.json | 259바이트 | `5987877feba283fd1972f1e712281c1c309cd3bc87a3908f168ee781267fec60` |

실제 사용자 경로에서 오프라인 전체 설치와 공개 최신 링크의 온라인 전체 설치를 각각 확인했습니다. 온라인 검사는 최신 `Setup.exe`를 내려받고 `--silent`로 실행해 최신 버전 조회·패키지 다운로드·검증·설치를 진행했습니다. 두 설치 모두 런타임 127개 파일의 해시, Windows 앱 등록·시작 메뉴·제거 프로그램 등록과 개인 UserAudio 보존을 통과했습니다. 설치 프로그램은 AE를 정상 종료한 상태에서 실행했습니다.

설치된 엔진을 AE 2026에서 직접 불러와 개체·텍스트·타이틀·장면 전환·도형 대표 5종의 적용, 숫자·좌표 컨트롤 변경과 원래 값 복구, 표현식, 개인 오디오 연결, PNG 렌더, 제거를 검사했습니다. 38개 확인 항목을 통과했습니다. 이 설치 후 검사는 위 110개 미리보기 재생 검사와 구분합니다.

## 1.1.0 런타임 검증

1.1.0 후보에서 아래 런타임 검사와 이전 미리보기 110개의 브라우저 재생 검사를 완료했습니다. 실제 사용자 경로의 1.1.0 오프라인 설치는 런타임 파일 126개의 SHA-256, Windows 앱·시작 메뉴·제거 프로그램 등록, 개인 오디오 보존까지 확인했습니다. 이 후보의 온라인 설치 검사는 진행하지 않았습니다. 아래 렌더 결과는 모션 엔진을 변경하지 않은 1.1.1에서도 참고할 수 있습니다. 새 미리보기 자산의 검증은 위에 별도로 기록했습니다.

타이틀·도형·카메라를 생성하는 네이티브 작업 흐름의 컨트롤 검사는 완료했습니다. 시간 계산·HD·세로 화면과 개인 오디오 연결의 완료된 검사 결과는 아래에 구분했습니다. 브라우저 검사는 영상의 디코딩·선택 상태·화면 밖 재생 중지를 확인하며, 클립의 전체 동작 구간에 대한 시각 검사를 대신하지 않습니다.

타이틀·도형 9개 클립은 전체 레이어 구간 앞뒤에 각각 0.5초 이상의 여유가 들어가도록 다시 생성했습니다. 교체 후 9개를 다시 선택하고 각 영상의 앞·중간·끝 27개 프레임을 브라우저에서 읽었습니다. 디코딩·선택·미디어 오류는 없었고, 나머지 101개 파일은 앞선 110개 검사 때와 같은 해시였습니다. 최신 110개 파일 모두 미디어 확인 목록의 SHA-256과 일치했습니다.

프레임 비교는 검사한 시점과 입력의 수치 결과입니다. 미리보기 디코드나 선택 상태 검사만으로 시각 일치 판정을 내리지 않습니다.

개인 오디오를 연결한 시험은 48kHz·스테레오·8초·16-bit PCM 35쌍입니다. 12쌍은 PCM 일치, 30쌍은 최대 진폭 차이 1 이내였고, 4쌍은 최대 2, 1쌍은 마지막 한 스테레오 프레임에서 최대 19였습니다. 비무음 29쌍의 시간 지연은 0, 최대 상대 RMS 차이는 0.0182902%였습니다. 청취상 동일성이나 모든 사용자 길이·볼륨·샘플레이트의 일치를 뜻하지 않습니다.

### UI·오디오·설치 검사

- 최종 `npm test` 전체 72개 검사를 통과했습니다.
- 그중 카드 내부 변형 선택, 전체 변형 보기, 적용 대상 유지, 개인 오디오 누락 안내와 미리보기 수치 처리 등 UI·미리보기 검사 16개를 통과했습니다.
- 개인 오디오 라이브러리의 누락 파일 처리, 등록 파일 찾기와 폴더 밖 경로 거부 검사 3개를 통과했습니다.
- 1.1.0 설치 프로그램을 컴파일하고 임시 폴더의 격리 검사 16개를 통과했습니다. 실패 복구, 다른 확장 보존, 제거 및 재설치 세대 보호를 포함하며 실제 Adobe 폴더나 사용자 레지스트리는 변경하지 않았습니다.
- 제품·CEP·카탈로그 버전 불일치를 패키징 전에 거부하는 검사 4개를 통과했습니다.
- 기본 GUI 유지, 무인 모드의 입력 제한·종료 코드·stderr, 격리 설치·손상 파일 거부·자체 제거를 포함한 `--silent` 검사 7개를 통과했습니다.
- 실제 브라우저에서 110개 변형의 선택·하단 이름·In/Out/Both 또는 Apply 표시를 검사했습니다. From End/From Start의 inline 선택, 전체 변형 카드 2개와 Back 후 선택 유지도 통과했습니다. 이 실행에서는 AE 호출이나 가짜 호스트 응답을 사용하지 않았습니다.
- 자체 A/B 장면은 서로 다른 산·호수와 도시·달 이미지이며 각각 1280×720입니다. AE 렌더 클립이 연결된 항목은 그 클립을 우선 재생하고 화면 밖에서는 일시정지합니다.
- 개인 효과음은 설치 폴더 밖 UserAudio에서 읽습니다. 공개 패키지에 효과음 파일을 포함하지 않습니다.

이 검사는 선택한 레이어의 실시간 렌더, 모든 AE 버전 호환성 또는 전체 110개 항목의 시각 검증 완료를 뜻하지 않습니다. 지원 환경은 위 Windows·AE 조합입니다.

### 글꼴과 개인 자산

기본 타이틀은 `Montserrat-ExtraBold`, `Montserrat-Black`, `Montserrat-Bold`를 사용합니다. 글꼴은 패키지에 포함되지 않습니다. 패널에 고정된 대체 글꼴은 없으며, 설치되지 않은 글꼴의 처리는 After Effects에 따릅니다. 타이틀별 설정은 [사용 안내](user-guide.md#타이틀-기본-글꼴)에 있습니다.

미리보기 A/B 이미지는 자체 제작 자산입니다. 개인 효과음은 별도 UserAudio에서 읽으며 공개 패키지에 파일을 넣지 않습니다. 최종 패키지 생성과 실제 설치 뒤에는 설치 영수증을 별도 배포 기록에 추가합니다.

## 1.0.0 검증 이력

아래는 이미 배포한 1.0.0에서 확인한 이력입니다. 변경된 1.1.0 엔진의 최종 검증 결과를 대신하지 않습니다.

### After Effects 엔진 검사

- 43개 프리셋, 방향별 변형을 포함한 110개 항목의 적용과 330개 PNG 렌더를 검사했습니다.
- 검사 시점의 표현식 오류는 0개였습니다.
- 키프레임·사용자 댓글 보존, 제거 후 복원, 여러 레이어 적용, In/Out 병합 등 11개 작업 검사를 통과했습니다.
- 타이틀 텍스트·폰트·트래킹·색상, 도형 크기·색상, 카메라 효과·길이와 다른 인스턴스의 보존 등 79개 컨트롤 검사를 통과했습니다. 늘린 길이의 후반부도 PNG로 렌더해 확인했습니다.
- Typewrite의 색상 변경은 실제 렌더 픽셀에서 확인했습니다.

### 네이티브 CEP 패널 검사

실제 After Effects 패널에서 전환 변형 하나의 Both 적용과 편집을 검사했습니다. Distance의 초기값 220을 420으로 바꾼 뒤 네이티브 Undo로 220, Redo로 420이 되는 것을 확인했습니다. 이 과정에서 경고가 발생하지 않았습니다.

같은 인스턴스를 제거한 뒤 효과가 0개가 되고, 사용자 댓글과 표현식이 적용 전 기준 상태로 복구되는 것을 확인했습니다. 패널 슬라이더의 초기값·범위와 컨트롤 식별자도 확인했습니다.

### 지원 범위

이 버전은 Windows용 After Effects CEP 패널입니다. 실제 사용 검증은 위 환경에서 수행했으며, 다른 OS나 모든 AE 버전에 대한 호환성을 보증하지 않습니다.

모션·텍스트 프리셋은 선택한 레이어에 적용하고, 타이틀·도형·카메라 프리셋은 새 레이어를 추가합니다. 카메라 효과는 아래 레이어에 작용하는 조정 레이어입니다. 타이틀 기본 글꼴은 Arial Bold이며 Edit에서 바꿀 수 있습니다.

미리보기는 대표 움직임을 Canvas로 보여줍니다. 선택한 레이어를 실시간으로 렌더하는 기능은 아닙니다. 긴 그림자는 여러 기본 효과를 겹쳐 만들므로 길이를 크게 늘리거나 가는 선에 적용하면 경계가 보일 수 있습니다.

같은 레이어에서 같은 변형의 In과 Out은 합칠 수 있습니다. 서로 다른 변형을 섞는 경우에는 기존 프리셋을 제거한 뒤 적용하세요. 애니메이션이 있는 Source Text에 스트로크 스타일을 덮어쓰는 작업은 기존 내용을 보존하기 위해 지원하지 않습니다. Edge 프리셋을 적용한 뒤 레이어의 기본 크기를 크게 바꿨다면 다시 적용하세요.

사용자 프리셋 생성·저장 기능은 이 버전에 포함되지 않습니다.

### 설치와 소스 검증

설치 프로그램의 16개 격리 시험을 통과했습니다. 신규 설치, 오프라인 설치, 손상 파일 거부, 경로 검증, 업데이트 실패 시 복구, 설치 제거와 실행 중 제거 프로그램의 파일 정리를 포함합니다.

실제 오프라인 GUI 설치에서도 사용자별 Windows 앱 등록(HKCU), 시작 메뉴, 제거 프로그램과 설치된 런타임 파일 11개의 SHA-256 일치를 확인했습니다.
