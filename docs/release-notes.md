# Contentrium Preset 1.0.0

After Effects용 프리셋 패널의 첫 배포입니다. 43개 프리셋과 110개 변형을 제공합니다.

- Browse에서 카테고리, 검색, 즐겨찾기와 애니메이션 미리보기로 프리셋을 탐색합니다.
- 변형을 고르고 In, Out, Both 또는 Apply로 적용합니다.
- Edit에서 선택한 레이어의 수치, 색상, 위치, 시간 등 지원되는 컨트롤을 조정합니다.
- Windows 사용자 계정별 설치·업데이트·제거를 제공합니다.

## 다운로드

| 파일 | 용도 |
| --- | --- |
| [Setup.exe](https://github.com/contentriumkorea/contentrium-preset/releases/download/v1.0.0/Setup.exe) | 설치 버튼을 누르면 최신 버전을 다운로드하고 설치 |
| [Portable.zip](https://github.com/contentriumkorea/contentrium-preset/releases/download/v1.0.0/Portable.zip) | 전체 패키지를 압축 해제한 뒤 Install.cmd로 오프라인 설치 |
| [release-manifest.json](https://github.com/contentriumkorea/contentrium-preset/releases/download/v1.0.0/release-manifest.json) | Portable.zip의 파일 크기와 SHA-256 |

설치 전 After Effects를 닫아 주세요. 설치 후 **창 → 확장 → Contentrium Preset**에서 패널을 엽니다. 포터블 패키지도 After Effects 호스트 등록이 필요한 CEP 패널입니다.

검증 환경은 Windows 11, After Effects 2026(26.5)입니다. 애니메이션 미리보기는 대표 움직임을 보여주며, 선택 레이어의 실시간 렌더 기능은 아닙니다.
