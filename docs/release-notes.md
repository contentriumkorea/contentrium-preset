# Contentrium Preset 1.2.0

After Effects용 프리셋 탐색·적용·편집 패널입니다. 43개 프리셋·110개 방향 변형과 자체 Contentrium Grid 애니메이션 폰트를 제공합니다.

- 적용한 레이어의 설정 편집, 타임라인 IN·OUT 조절, 설정 복사·붙여넣기·초기화와 보조 도구를 보강했습니다.
- 직접 프리셋 저장, 동일 이름 속성 구분, 표현식 참조와 마스크 색상 저장을 개선했습니다.
- 다중 패널·속성 세트·3D 전환 확인 처리를 개선했습니다.
- 폴더 추가는 패널 안에 경로를 입력합니다. 파일 탐색기 주소 표시줄에서 경로를 복사하고, 다음 화면에서 저장 위치를 선택한 뒤 추가하세요.

설치 전 After Effects를 닫아 주세요. 설치 후 **창 → 확장 → Contentrium Preset**에서 엽니다. 현재 사용자 계정에 Windows 앱·시작 메뉴·제거 프로그램을 등록합니다. 포터블 패키지도 AE 호스트 등록이 필요한 CEP 확장입니다.

검증 환경은 Windows 11·AE 2026(26.5)입니다. 자동 테스트 1,428개가 통과했으며 실제 AE의 대표 공통 기능 시험을 별도로 수행했습니다. 임의 AEP 자동 미리보기와 단일 네이티브 컨트롤러는 활성화하지 않습니다. 효과음 파일은 포함하지 않습니다.
