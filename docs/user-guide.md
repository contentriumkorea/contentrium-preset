# 설치와 프리셋 팩

## 본체 설치

작업을 저장하고 AE를 닫은 뒤 Setup.exe를 실행하고 **설치**를 누르세요. 설치기가 공개된 최신 버전을 확인하고 본체를 내려받아 현재 사용자 계정에 설치합니다. 관리자 권한은 필요하지 않습니다.

인터넷 연결 없이 설치하려면 Portable.zip을 모두 압축 해제하고 Install.cmd를 실행하세요. 이 ZIP은 AE 확장 등록용 오프라인 패키지이며 독립 실행형 프로그램이 아닙니다.

## 프리셋 팩 등록

본체에는 프리셋 라이브러리가 포함되지 않습니다. 별도로 보유한 Contentrium Preset 전용 팩 ZIP이 필요합니다. 일반 ZIP이나 다른 제품의 팩을 직접 등록하는 기능은 제공하지 않습니다.

1. AE에서 **창 → 확장 → Contentrium Preset**를 엽니다.
2. **프리셋 팩 ZIP 등록**을 누릅니다.
3. ZIP을 선택하거나 파일 경로를 붙여넣고 **등록**을 누릅니다.
4. 파일 확인과 압축 해제가 끝나면 프로젝트를 저장하고 AE를 다시 엽니다.

팩 등록은 사용자 데이터 폴더에서 이루어지며 관리자 권한이 필요하지 않습니다. ZIP 크기와 압축을 푼 크기를 합친 여유 공간이 필요합니다. 본체 업데이트 시 팩을 다시 내려받을 필요는 없습니다.

현재는 전체 라이브러리를 담은 한 팩을 활성화하는 방식입니다. 새 팩은 활성 라이브러리를 교체하며 기존 팩 파일, 즐겨찾기, 사용자 설정과 다른 사용자 라이브러리는 삭제하지 않습니다. 적용 검증을 마친 변형만 활성화됩니다. 목록에 표시되는 모든 항목의 적용을 보장하지 않습니다.

## 업데이트와 제거

AE를 닫고 Setup.exe를 다시 실행하면 최신 본체로 업데이트됩니다. 설치 오류 시 기존 설치를 복구합니다. Windows 설정의 앱 목록에서 제거할 수 있으며, 별도로 등록한 사용자 팩은 삭제하지 않습니다.

## 지원 범위

Windows 11과 After Effects 2026에서 확인했습니다. 실제 AE 작업 환경에서의 팩 호환성은 팩이 제공하는 지원 정보에 따라 달라집니다. 이번 버전의 새 ZIP 등록 기능은 격리 설치·압축 해제·카탈로그 연결로 확인했으며, 기존 AE 설치본을 교체하는 실사용 전환 시험은 별도입니다.

팩 파일의 해시는 손상 확인용이며 배포자 인증을 위한 디지털 서명은 아닙니다. 직접 보유하거나 신뢰하는 배포자로부터 받은 팩을 사용하세요.
