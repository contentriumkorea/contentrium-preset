# Contentrium Preset 사용 안내

43개 프리셋과 110개 변형을 제공하는 After Effects용 패널입니다. 검증 환경은 Windows 11, After Effects 2026(26.5)입니다.

설치 전에 작업을 저장하고 After Effects를 닫으세요. Setup.exe에서 설치를 누르면 최신 버전을 다운로드하고 현재 사용자 계정에 설치합니다. 포터블·오프라인 패키지 Portable.zip은 모든 파일을 압축 해제한 뒤 Install.cmd로 오프라인 전체 설치할 수 있습니다. 두 방식 모두 After Effects 안에서 사용하는 CEP 패널을 등록합니다.

After Effects를 열고 창 → 확장 → Contentrium Preset에서 패널을 여세요. 메뉴 이름은 Adobe 버전에 따라 확장(레거시)으로 표시될 수 있습니다.

Browse에서 왼쪽 카테고리를 펼치거나 검색어를 입력하세요. 별표로 개인 즐겨찾기를 관리하고, 썸네일 크기를 조절할 수 있습니다. 카드를 선택하면 아래에 변형 목록이 겹쳐 열리며 주변 카드의 위치와 미리보기 재생은 유지됩니다. 목록이 길면 내부를 스크롤하세요. 예를 들어 From End와 From Start 중 하나를 선택하면 해당 미리보기와 하단 변형 이름이 함께 바뀝니다. View all at once를 누르면 모든 변형을 별도 카드로 비교할 수 있습니다. Back으로 원래 목록에 돌아옵니다.

선택한 카드를 다시 클릭하거나 목록의 빈 영역을 클릭하면 선택이 해제됩니다. 같은 위치를 더블클릭하면 기본 방식으로 적용합니다. 방향키 또는 소문자 wasd로 카드를 이동하고 Alt+위/아래 또는 대문자 W/S로 변형을 고를 수 있습니다. 키보드로 고른 카드에 1초 머물면 방향 목록이 펼쳐집니다. 프리셋을 적용하는 동안 미리보기는 잠시 멈췄다가 작업이 끝나면 다시 재생합니다.

라벨 필터에서 여러 색을 차례로 추가하면 해당 색의 프리셋을 함께 볼 수 있습니다. 색상 태그의 ×는 그 필터 하나만 해제합니다. **필터 모두 해제**는 검색어·즐겨찾기 필터·색상 필터를 초기화하며, 저장한 즐겨찾기와 라벨은 유지합니다. 라벨 자체를 모두 지우려면 패널 메뉴의 **모든 저장 라벨 지우기**를 사용하세요.

검색어는 잠깐 입력을 멈추면 반영됩니다. `Motion Left`처럼 분류와 방향을 함께 검색하면 해당 방향의 미리보기를 보여 줍니다. 같은 항목의 서로 다른 방향 이름을 섞어 검색하면 일치 결과로 처리하지 않습니다.

일반 목록과 검색·필터 목록은 선택과 방향을 따로 기억합니다. 필터를 모두 해제하면 일반 목록에서 고른 프리셋과 방향으로 돌아옵니다. 폴더 또는 카드의 우클릭 메뉴에서 **이 폴더에 집중**을 고르면 해당 분류만 탐색합니다. 위쪽 화살표로 상위 폴더에 집중하거나 **Show all items**로 전체 목록에 돌아옵니다. 분류 트리의 위·아래 키는 폴더를 선택하고 Enter는 하위 폴더를 펼치거나 접습니다.

적용할 레이어를 선택하고 In, Out, Both 또는 Apply를 누르세요. 프리셋마다 적용 방식과 지원되는 레이어가 다릅니다. 하단에 표시된 변형이 적용 대상입니다. 개체 애니메이션은 투명 로고 PNG, 텍스트·타이틀은 배경 이미지 없이 글자만 보여줍니다. 장면 전환은 보라·청록의 차가운 A 장면과 코럴·골드의 따뜻한 B 장면을 사용합니다. 화면 밖의 영상은 멈추고 다시 보이면 재생합니다. 선택 레이어의 실시간 렌더 기능은 아닙니다.

## 자동 Edit와 탭 고정

상단의 전환 모드가 **Auto**일 때 프리셋이 적용된 레이어를 선택하면 Edit로 이동합니다. 선택을 해제하거나 편집할 프리셋이 없는 레이어로 옮기면 Browse로 돌아갑니다. Auto 상태에서는 Browse나 Edit 탭을 직접 눌러도 자동 모드를 유지합니다. 같은 레이어에서는 고른 탭을 유지하고, 다른 레이어를 선택하면 자동 전환을 다시 판단합니다. 탭을 고정하려면 전환 모드에서 Browse 또는 Edit를 선택하세요. 고정 상태에서 반대 탭을 누르면 그 탭으로 고정됩니다. 별도 Edit 패널이 열려 있으면 기본 패널은 Browse를 유지합니다.

패널 메뉴에서 **별도 Edit 패널**을 열면 Browse와 Edit를 나란히 배치할 수 있습니다. **Edit 패널 다시 결합**으로 돌아옵니다. **새 Browse 패널**은 다른 분류를 따로 볼 때 사용하세요. 창별 탐색 상태는 별도로 유지하며 즐겨찾기와 라벨은 공유합니다.

## Edit와 전환 타이밍

Edit의 그룹을 펼쳐 수치, 색상, 위치, 시간 등을 조절합니다. 숫자에는 절대값 또는 `+=10`, `-=10`을 입력할 수 있습니다. 여러 레이어의 값이 다르면 ‘서로 다른 값’으로 표시합니다. 이때 상대 입력으로 각 레이어의 기존 값에 같은 변화량을 더하거나 뺄 수 있습니다. 수치 이름을 좌우로 드래그하면 값을 조절하고, Shift를 누르면 정밀하게 움직입니다.

After Effects 26에서는 패널 안에서도 **Ctrl+Z**로 실행 취소, **Ctrl+Shift+Z**로 다시 실행할 수 있습니다. Mac에서는 Ctrl 대신 Command를 사용하세요. Edit 속성을 입력하거나 드래그하는 중이라면 변경을 먼저 반영한 뒤 실행 취소합니다. 검색창 등 일반 입력란에서는 입력 내용의 실행 취소를 유지합니다. 처리 중 선택 대상이나 프로젝트가 달라지면 요청을 중단하므로 현재 선택을 확인한 뒤 다시 누르세요. 다른 AE 버전에서는 AE의 편집 메뉴를 사용하세요.

시간 입력은 초, `12f` 같은 프레임 수, `00:00:01:12` 같은 타임코드를 받습니다. 위·아래 화살표는 한 프레임, Shift와 함께 누르면 열 프레임씩 이동합니다. 각도는 `2x+30`처럼 회전 수와 각도를 함께 입력하거나 다이얼로 조절할 수 있습니다.

적용된 전환은 레이어 타임라인의 마커로 길이를 조절합니다. 개체·텍스트 전환의 **TR In**은 들어오기 종료, **TR Out**은 나가기 시작 위치입니다. TR In을 레이어 시작에 가깝게 옮기면 들어오기가 짧아지고, TR Out을 레이어 끝에 가깝게 옮기면 나가기가 짧아집니다. 두 마커 사이가 본문 구간입니다. 나가기 길이는 레이어의 마지막 표시 프레임을 기준으로 계산합니다. 레이어의 시작·끝을 자르면 그 경계와 마커 사이의 길이도 달라집니다. 마커를 옮기면 Edit의 길이 표시도 갱신됩니다. 입력 중인 초안과 진행 중인 드래그는 자동 갱신으로 덮어쓰지 않습니다.

프리컴포지션에는 **IN / OUT**, 장면 전환에는 **CUT** 마커가 표시됩니다. Edit의 Timeline 그룹에서도 위치를 입력하거나 **재생 헤드에 맞춤**을 사용할 수 있습니다. Timeline의 값은 마커의 컴포지션상 위치이며 Duration 값은 전환 길이입니다. 제거한 마커를 다시 사용할 때는 표시된 **마커 추가**를 누르세요. 이전 형식 안내가 나오면 **타임라인 업데이트**로 선택한 프리셋을 새 형식으로 바꿉니다.

적용 목록 위에서 **전체 / In / Out / Effects** 범위를 고른 뒤 복사·붙여넣기·제거·초기화를 사용할 수 있습니다. 개별 프리셋 행의 **찾아보기**는 해당 변형을 Browse에서 찾습니다. 사용할 수 없는 작업은 비활성화되거나 상태줄에 이유가 표시됩니다.

## 그룹별 속성 Presets

Edit의 지원되는 그룹 오른쪽 **Presets**를 누르면 저장한 속성 조합을 불러올 수 있습니다. **Save As…**로 현재 그룹에 이름을 붙여 저장하고, 목록의 이름을 누르면 적용합니다. 현재 값과 일치하는 프리셋이 있으면 **현재 프리셋 삭제**가 표시됩니다. 서로 다른 값이 섞인 그룹은 저장할 수 없습니다.

속성 프리셋은 해당 프리셋·방향·속성 그룹에 연결됩니다. 다른 방향이나 다른 종류의 그룹을 바꿔 적용하는 메뉴가 아닙니다.

## 프리컴포지션 삽입·교체

타이틀·도형 등에서 지원하는 **Animate In / Animate Out**을 선택하고 Apply로 추가합니다. 효과음이 있는 항목에는 **효과음 추가**가 표시됩니다. 장면 전환은 CUT을 기준으로 동작하므로 개별 In / Out 옵션을 제공하지 않습니다.

효과음이 있는 프리셋의 하단에는 미리듣기 음소거와 볼륨이 표시됩니다. 준비된 개인 미리듣기 파일이 있으면 선택한 영상 하나에 맞춰 재생하고, 선택 해제·효과음 추가 해제·화면 이탈·적용 작업 중에는 멈춥니다. 개인 미리듣기 파일이 없으면 해당 상태를 표시합니다. 효과음 적용용 원본 파일만 등록한 경우에는 미리듣기 파일이 자동으로 생성되지 않습니다. **미리보기 효과음 설정**에서 개인 WAV의 시작 위치·구간·속도·음량·페이드를 정하고 **저장하고 준비**를 누르면 선택한 영상 길이에 맞춘 미리듣기를 만듭니다. 설정 창의 미리듣기는 다른 창으로 이동하면 멈추고 자동으로 재개되지 않습니다. 영상이나 원본 WAV가 바뀌면 저장된 파일을 다시 확인하며, 영상이 달라졌다는 안내가 나오면 배치를 확인하고 다시 저장하세요.

교체할 프리컴포지션을 하나 선택하면 **Replace**를 사용할 수 있습니다. **교체 시 보존**에서 텍스트, 텍스트 속성, 변형 속성, 기타 속성 중 유지할 항목을 고르세요. 지원하지 않는 Texture 옵션은 비활성화됩니다.

## 사용자 라이브러리

**폴더 추가**를 누르고 파일 탐색기 주소 표시줄에서 복사한 폴더 경로를 붙여넣으세요. **다음**을 누르면 미리보기 저장 위치를 선택할 수 있습니다. 기본값은 프로그램 내부 캐시이며 **추가**를 눌러야 폴더가 등록됩니다. 경로 입력과 저장 위치 화면에서 취소하면 등록하지 않습니다. 폴더가 존재하지 않으면 오류를 표시하며 다른 폴더로 대체하지 않습니다.

사용자 라이브러리에 많은 항목이 있어도 Browse의 검색과 방향키, Home/End로 전체 항목을 탐색할 수 있습니다. 화면에 보이는 미리보기부터 불러오며, 방향 옵션을 펼쳐도 다른 줄의 위치는 유지됩니다. Library 상세 설정은 한 페이지에 50개씩 표시합니다. 이전·다음·첫·마지막 페이지 버튼을 사용하거나 Browse에서 항목을 선택하고 **상세 설정**을 누르면 해당 페이지로 이동합니다. 오디오 피치·Reverse와 이미지 시퀀스 FPS는 패널이 열린 동안 페이지나 탭을 바꿔도 유지됩니다.

왼쪽 아래 **사용자 라이브러리** 또는 패널 메뉴에서 엽니다. **폴더 추가**로 로컬 미디어 폴더를 등록하고 가져올 항목을 선택하세요. **새로고침**으로 파일 목록을 다시 읽습니다. 폴더의 등록 해제는 라이브러리 연결을 제거합니다.

등록한 파일과 직접 저장한 프리셋은 Browse의 **User Library**에도 나타납니다. 내장 프리셋과 함께 검색·즐겨찾기·라벨을 사용할 수 있고, 이름이 같은 등록 폴더도 별도로 구분합니다. 카드를 고른 뒤 **가져오기** 또는 **적용**을 누르세요. 호환되는 미디어는 **선택 항목 교체**로 바꿀 수 있습니다. **상세 설정**은 해당 라이브러리 항목의 오디오·시퀀스 옵션으로 이동합니다.

이미지·영상·오디오는 **크게 미리보기**로 확인할 수 있습니다. 미리보기 파일이 없는 사용자 프리셋·FFX·AEP에는 준비되지 않은 상태가 표시됩니다. 원본을 찾지 못한 즐겨찾기나 라벨 항목은 표시를 유지하면서 가져오기를 막으며, 같은 경로에 파일을 복구한 뒤 새로고침하면 다시 사용할 수 있습니다.

**선택 항목 교체**는 레이어의 앵커, 변형 값과 키프레임, 효과, 마커를 유지합니다. 더 짧은 영상이나 컴포지션으로 교체하면 AE의 소스 길이 제한에 따라 레이어 끝이 줄어들 수 있습니다. 타임 리맵을 자동으로 켜거나 소스 길이를 늘리지는 않습니다. Undo로 교체를 되돌리면 이전 소스와 길이가 복구됩니다.

선택한 레이어를 저장하려면 Edit의 **Save Preset**을 누르고 이름을 입력하세요. **선택한 속성만 저장**을 켜면 AE 타임라인에서 선택한 속성만 저장합니다. **글자 내용과 서식도 포함**을 켜면 지원되는 단일 스타일의 한 줄 포인트 텍스트도 함께 저장합니다. 두 옵션은 매번 꺼진 상태로 시작합니다. 기본 저장은 적용된 프리셋의 설정을 저장하며, 일반 레이어에서는 애니메이션·효과·도형 등 지원되는 속성을 저장합니다.

저장한 속성 프리셋을 라이브러리에서 가져오면 **저장한 글자로 바꾸기**와 **기존 키프레임과 표현식 덮어쓰기**를 선택할 수 있습니다. 기본값은 모두 꺼져 있습니다. 기존 애니메이션과 충돌하면 적용을 중단하므로 의도적으로 바꿀 때만 덮어쓰기를 켜세요. 글자를 포함하지 않은 프리셋에서는 글자 교체가 비활성화됩니다. 대화상자를 연 뒤 레이어나 프로젝트를 편집했다면 창을 닫고 대상을 다시 선택하세요.

일반 속성 저장은 레이어·푸티지·프리컴포지션 간 연결을 자동으로 묶어 내보내는 기능은 아닙니다. 표현식의 외부 참조도 자동으로 바꾸지 않습니다. 여러 스타일·여러 줄·박스 텍스트 등 지원되지 않는 값은 오류로 안내합니다. 저장한 사용자 프리셋은 라이브러리에서 다시 가져올 수 있으며, 관리되는 항목에는 제거 버튼이 표시됩니다. AEP에 여러 컴포지션이 있으면 가져올 컴포지션을 고르는 창이 열립니다. 이때 AEP의 항목은 이미 AE 프로젝트에 들어와 있으며, 취소하면 타임라인 추가나 소스 교체만 취소됩니다. 같은 패널 세션에서 원본과 프로젝트가 유지되는 동안 다시 선택하면 가져온 항목을 재사용합니다. 레이어 추가·교체는 한 번의 Undo로 되돌릴 수 있고, 프로젝트로 가져온 AEP 항목은 유지됩니다. 원본 파일이나 프로젝트가 바뀐 뒤에는 항목을 다시 선택하세요.

이미지 시퀀스는 첫 프레임과 프레임 수를 표시합니다. 누락된 프레임이 있으면 사유를 보여 주고 가져오기를 제한합니다. FPS를 비우면 After Effects의 원본 해석을 사용하며, 직접 지정하려면 0 초과 99 이하의 값을 입력하세요. 개별 정지 이미지도 별도 항목으로 유지됩니다.

오디오의 **파형·피치 미리듣기**에서는 재생·일시 정지·처음부터·파형 탐색·음소거·볼륨·피치·Reverse를 사용할 수 있습니다. 피치는 -24~24반음입니다. 100 MiB를 넘는 파일은 기본 플레이어를 사용합니다.

피치나 Reverse를 바꾼 뒤 가져오기·교체를 누르면 변형한 WAV를 만들어 가져옵니다. 결과는 `%APPDATA%\Contentrium\Preset\ProcessedAudio`에 보관합니다. 미리듣기 볼륨과 음소거는 가져오는 오디오에 반영되지 않습니다. 변형을 만들지 못하면 오류를 표시하므로 상태줄을 확인하세요.

## Tools

**Tools**에는 네 가지 도구가 있습니다. 상단의 도구 이름으로 해당 영역에 이동할 수 있습니다.

- **이징**: 선택한 키프레임의 모드와 In / Out 영향도를 지정합니다. 그래프 핸들을 드래그하거나 수치를 입력하세요. 값 연결을 켜면 두 영향도가 함께 바뀝니다. 이징 프리셋을 저장·삭제·재정렬하고 기본 목록을 복원할 수 있습니다.
- **키프레임**: 복사, 값·이징 붙여넣기, 미러, 복제, 반전, 첫 키·마지막 키 정렬과 순서별 이동을 제공합니다. **같은 순서 키 선택** 버튼을 누른 뒤 **첫 키 기준** 또는 **마지막 키 기준**을 선택하면 다른 선택 레이어의 대응 키를 고릅니다. 화살표 키로 메뉴를 이동하고 Enter로 선택하거나 Esc로 닫을 수 있습니다.
- **앵커 포인트**: 아홉 방향 중 위치를 고르고 기존 키프레임 변경 또는 새 키프레임 삽입 방식을 선택합니다. 새 키 삽입은 키가 있는 속성에 재생 헤드 시각의 키를 추가합니다. 정적인 앵커·일반 Position은 키를 새로 만들지 않습니다. 마스크와 부모 레이어, 3D 변환 및 분리된 Position 축도 처리합니다.
- **전환 이동**: In / Out 전환과 마커를 프레임 단위로 이동합니다. 레이어·전환의 엇갈리기 순서를 정하거나 시작·끝·마커를 재생 헤드에 맞춥니다.

선택한 레이어나 키프레임이 도구 조건에 맞지 않으면 상태줄의 안내를 확인하세요.

각 도구의 **별도 창으로 열기** 버튼으로 도구 전용 패널을 열고 AE 작업 영역에 도킹할 수 있습니다. AE의 창 → 확장 메뉴에서도 Easing, Keyframes, Anchor Point, Transition Shifter 패널을 열 수 있습니다. 이징 그래프의 빈 영역을 클릭하면 현재 값을 적용하고, 핸들을 드래그하면 값을 조정합니다. 키프레임 작업이 성공하면 누른 버튼에 잠시 확인 표시가 나타납니다.

## 탐색·설정

카드나 분류를 우클릭하면 즐겨찾기·라벨·분류 보기 등의 메뉴가 열립니다. 분류 라벨은 항목에 상속되고, 항목에 지정한 라벨이 우선합니다. 검색·즐겨찾기·라벨 필터를 함께 사용할 수 있습니다. 방향키 또는 WASD로 탐색하고, Home / End로 처음·끝에 이동합니다. 그리드에서 Alt+위·아래는 변형을 바꿉니다.

패널 메뉴의 **설정**에서 비활성 패널의 미리보기 정지, 적용 시 모션 블러, 프리컴포지션 삽입 위치, 사용자 미디어 복사·연결을 선택합니다. 지원하지 않는 단일 효과 컨트롤러 옵션은 비활성화됩니다. 업데이트·도움말·문제 보고·제품 정보도 패널 메뉴에서 열 수 있습니다.

## 타이틀 기본 글꼴

타이틀의 기본 모양에는 아래 Montserrat 글꼴이 사용됩니다. 글꼴 파일은 패키지에 포함되지 않으며 설치 프로그램도 글꼴을 설치하지 않습니다. 기본 모양을 사용하려면 해당 스타일이 설치되어 있어야 합니다.

| 타이틀 | 기본 스타일 | Edit의 Font에 표시되는 이름 |
| --- | --- | --- |
| 1-Line Basic Title 1 · 4개 변형 | Montserrat ExtraBold | `Montserrat-ExtraBold` |
| 2-Line Basic Title 2 · 첫 줄 | Montserrat Black | `Montserrat-Black` |
| 2-Line Basic Title 2 · 둘째 줄 | Montserrat Bold | `Montserrat-Bold` |
| 3-Line Basic Title 2 - Center · 세 줄 | Montserrat ExtraBold | `Montserrat-ExtraBold` |

Edit의 Font에서 설치된 글꼴 계열과 스타일을 선택할 수 있습니다. 다른 글꼴을 사용하면 글자 폭과 줄 배치가 달라질 수 있습니다. 필요한 글꼴이 없을 때 이 패널이 특정 글꼴로 대체하지는 않으며, After Effects의 글꼴 대체 동작을 따릅니다. 모션·텍스트 프리셋은 선택한 레이어의 글꼴을 사용합니다.

타이틀의 각 줄에는 굵게, 기울임, 행간, 자동 행간과 왼쪽·가운데·오른쪽 정렬 컨트롤이 있습니다. 행간을 직접 지정하면 자동 행간이 해제됩니다. 복사·붙여넣기는 이 서식도 함께 유지합니다. 글꼴 목록에서 현재 글꼴을 찾지 못하면 그 이름을 그대로 표시하며, **글꼴 목록 새로고침**으로 다시 불러올 수 있습니다. 한글 등 일부 글자가 대체 글꼴을 사용 중이면 전체 문자를 지원하는 글꼴을 직접 선택하세요.

Source Text에 키프레임·표현식이 있거나 문자별 서식이 섞여 있으면 해당 서식을 보존하기 위해 지원하지 않는 편집을 비활성화하고 이유를 표시합니다. 끝의 빈 줄은 경고만 표시하고 보존합니다.

처음 여는 패널에는 메뉴 위치와 사용 안내가 표시됩니다. 패널 메뉴의 **처음 사용 안내**로 다시 열 수 있습니다. **제품 정보 → 버전 정보 복사**에서는 프로그램과 AE 버전을 복사할 수 있습니다.

## 사용자 항목의 미리보기

사용자 라이브러리의 영상과 이미지 시퀀스는 12프레임 썸네일을 만듭니다. 카드 위에서 마우스를 좌우로 움직여 장면을 확인하세요. 영상의 **크게 미리보기**에는 재생·탐색 컨트롤이 유지됩니다. 파일을 바꾼 뒤 새로고침하면 원본 내용을 다시 확인해 미리보기를 갱신합니다.

프리셋·FFX·프로젝트 항목은 **현재 컴포지션으로 미리보기 만들기**를 사용할 수 있습니다. 원하는 결과를 AE 컴포지션에 준비한 뒤 작업 영역을 정하고 누르세요. 이 작업은 열린 컴포지션을 촬영하며, 선택한 FFX나 프로젝트 파일을 자동으로 실행하지 않습니다. 생성 중에는 진행 상태와 **생성 중지**가 표시됩니다.

## 사용자 미디어를 텍스처로 적용

AE에서 도형·텍스트·영상 등 대상 레이어 하나를 선택하고, 사용자 라이브러리의 이미지·영상·이미지 시퀀스에서 **Texture**를 누르세요. 대상의 모양으로 잘린 텍스처 레이어가 추가됩니다. 대상의 표시 상태, 잠금, 변형과 사용자 마커는 유지됩니다.

추가된 텍스처를 선택하면 Auto 모드에서 Edit으로 전환됩니다. **Duration**은 텍스처의 표시 길이, **Color**는 색상, **Choke**는 윤곽의 확대·축소를 조절합니다. 영상과 시퀀스는 표시 구간 동안 반복되며 오디오는 삽입하지 않습니다. 시퀀스의 FPS는 가져오기와 동일하게 지정할 수 있습니다.

다른 이미지를 선택한 뒤 **텍스처 교체**를 누르면 대상 연결과 기존 색상·윤곽을 유지하여 소스를 바꿉니다. 복제한 텍스처의 컨트롤을 바꿔도 다른 복제본에 영향을 주지 않습니다. 복사·붙여넣기, 초기화, 제거, 사용자 프리셋 저장을 사용할 수 있으며, 저장한 프리셋은 원본 미디어 파일을 계속 참조합니다. 원본 파일을 이동했다면 라이브러리 경로를 확인하세요.

AE에서 텍스처의 Color·Choke에 직접 키프레임이나 표현식을 추가했다면, 해당 컨트롤 편집과 텍스처 교체는 중단되고 안내가 표시됩니다. 기존 애니메이션을 보존하기 위한 제한이며, 해당 속성은 AE에서 계속 편집할 수 있습니다.

## 색상조합

Edit의 **팔레트 슬롯 지정**에서 함께 다룰 색상 속성을 직접 선택하세요. **색상조합 저장**으로 현재 색상을 저장하고, 저장된 조합이나 이전·다음 버튼으로 적용합니다. **Custom**은 저장된 조합과 현재 값이 다르다는 표시입니다. 초기화는 슬롯을 지정했을 때의 색상으로 돌아갑니다.

색상조합은 지정한 속성 순서에 연결됩니다. AE에서 다른 편집을 하거나 Undo를 사용한 뒤 슬롯을 다시 지정하라는 안내가 나오면 대상을 확인해 재지정하세요. 색상 필드의 **AE 색상 선택기**는 RGB 색상을 선택하며, 취소하면 값을 바꾸지 않습니다.

## 애니메이티드 폰트

Browse의 **Animated Fonts**에서 스타일을 고르고 글자를 입력한 뒤 **Add**를 누르세요. 기본 제공 **Contentrium Grid**는 영문 대·소문자, 숫자, 공백과 `. - ! ? :`를 지원합니다. 소문자는 작은 대문자 형태로 표시됩니다. 스타일마다 지원하는 글자와 최대 길이가 다르며, 지원하지 않는 글자는 추가 전에 안내합니다.

추가한 레이어는 Edit에서 크기·색상·자간·글자별 위치와 IN·OUT 속도를 조절합니다. 타임라인의 IN·OUT 마커를 옮겨 애니메이션 길이를 바꿀 수도 있습니다. 프로젝트에는 벡터 애니메이션이 저장되므로 팩 파일이 없는 컴퓨터에서도 기존 결과를 재생할 수 있습니다. 팩이 없으면 새로 추가하거나 설정을 바꾸는 기능은 잠깁니다.

패널 메뉴의 **애니메이티드 폰트 팩**에서 등록 폴더와 지원 글자를 확인할 수 있습니다. 추가 스타일은 `%APPDATA%\Contentrium\Preset\AnimatedFonts` 폴더에 `.cfont.json` 파일로 넣고 패널을 새로고침하세요. 폴더가 없으면 직접 만듭니다. 팩의 ID가 중복되거나 내용 확인값이 맞지 않으면 안내를 표시하고 등록하지 않습니다. 추가 팩 폴더는 프로그램 업데이트·제거 후에도 유지됩니다.

## 개인 오디오 라이브러리

효과음 파일은 배포 패키지에 포함되지 않습니다. 개인 오디오 라이브러리는 Windows의 `%APPDATA%\Contentrium\Preset\UserAudio` 폴더를 사용합니다. 이 폴더는 프로그램·CEP 설치 폴더와 별개이므로 업데이트하거나 프로그램을 제거해도 유지됩니다.

패널 상단의 **Audio**를 누르면 폴더 경로와 `library.json` 예시를 복사할 수 있습니다. 필요한 효과음이 없으면 적용 후 상태줄과 Edit 탭에 미등록 안내가 나타납니다. 이 경우 영상 효과는 적용되지만 해당 효과음은 포함되지 않습니다.

1. 탐색기 주소창에 위 경로를 입력하고 폴더가 없으면 만듭니다.
2. 사용할 WAV, AIF, AIFF 또는 MP3 파일을 이 폴더에 넣습니다. 파일명은 `my-transition.wav`처럼 영문·숫자로 시작하고 영문·숫자·공백·점·밑줄·하이픈을 사용하세요.
3. 같은 폴더에 UTF-8 `library.json`을 만들고 프리셋의 오디오 키와 파일명을 연결합니다.

```json
{
  "schemaVersion": 1,
  "assets": {
    "transition-basic-05": "my-transition.wav"
  }
}
```

지원되는 오디오 키는 `bass-approach-01`, `bass-bend-01`, `slow-motion-17`, `slowdown-06`, `slowdown-07`, `swoosh-transition-03`, `swoosh-wood-01-minus24`, `transition-basic-05`, `transition-basic-09`, `transition-complex-11`, `transition-complex-14`입니다. 파일명은 해당 폴더 안의 파일만 지정합니다. 등록되지 않은 파일은 해당 효과음 없이 영상 효과를 적용합니다. 오디오를 사용하는 프리셋은 Edit의 Sound와 Volume 컨트롤로 조정할 수 있습니다.

파일을 등록한 뒤 이미 적용한 레이어를 선택하고 Edit의 **Sound를 껐다가 다시 켜면**, 등록된 누락 효과음만 추가합니다. 기존 효과음의 시간·키프레임·표현식과 애니메이션·전환 마커는 유지합니다. 파일이 아직 준비되지 않은 효과음은 미등록 상태로 남습니다. 적용할 때 **효과음 추가**를 해제했던 프리셋에는 이 복구 기능을 제공하지 않으므로, 효과음 추가를 켜고 다시 적용하세요.

설치 오류가 나오면 After Effects를 닫았는지, 인터넷 연결이 되는지 확인하고 다시 시도하세요. 파일 확인에 실패한 경우 설치가 진행되지 않습니다. 업데이트 도중 실패하면 이전 설치가 복구됩니다.

제거하려면 Windows 설정 → 앱 → 설치된 앱 → Contentrium Preset → 제거를 선택하세요. After Effects를 먼저 닫아 주세요. 다른 Adobe 확장은 보존됩니다. 개인 즐겨찾기는 별도 사용자 저장소에 남을 수 있습니다.

## 명령줄 설치·제거

자동화할 때는 Setup.exe에 `--silent`를 지정할 수 있습니다. 기본 실행은 설치 GUI를 엽니다. 무인 설치도 같은 최신 버전 조회·파일 확인·전체 설치와 AE 실행 중 중단 규칙을 사용합니다.

- 온라인 설치·업데이트: `Setup.exe --silent`
- 오프라인 전체 설치: `Setup.exe --silent --offline-directory "Portable.zip을 모두 압축 해제한 폴더"`
- 설치된 프로그램 제거: `Uninstall.exe --silent --uninstall`

성공 종료 코드는 0, 오류는 1이며, 무인 모드에서는 오류 대화상자 대신 stderr로 안내합니다. PowerShell에서는 `Start-Process -Wait -PassThru`로 실행 완료와 ExitCode를 확인하세요. 개인 오디오 폴더는 제거하지 않습니다.
